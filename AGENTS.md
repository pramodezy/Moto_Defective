# Repository Guidelines & Workflow

## Git Update Protocol
- **Repository Remote:** `https://github.com/pramodezy/Moto_Defective.git`
- **Default Branch:** `main`
- **Rule:** Whenever the user asks for changes:
  1. Carefully implement and verify the changes in the workspace.
  2. Always ask the user for explicit confirmation before updating the Git repository.
  3. Only upon receiving explicit confirmation from the user, stage, commit with a concise, descriptive message, and push to the remote repository.
